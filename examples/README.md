# Examples

These examples are deliberately small. Their purpose is to make the commands in the learning guides tangible, not to demonstrate production architecture.

- [`python/hello_data.py`](python/hello_data.py) — run a simple Python data calculation.
- [`api/fetch_post.py`](api/fetch_post.py) — call JSONPlaceholder with Requests.
- [`docker/`](docker/) — build and run a tiny Python container.
- [`sql/student_scores.sql`](sql/student_scores.sql) — create/query a small table.
- [`bash/summarise.sh`](bash/summarise.sh) — basic Bash script with input checking.
