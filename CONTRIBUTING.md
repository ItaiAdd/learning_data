# Contributing

Thanks for helping improve this learning guide.

## Good contributions

Useful contributions include fixing broken links, correcting technical errors, adding an accessible explanation, proposing a high-quality free learning resource, improving an example, or adding a small topic that is broadly useful to students entering data work.

Please prefer resources that are reputable, maintained, free to access where possible, and useful for learning rather than primarily promotional.

## Writing style

- Define jargon when it first appears.
- Explain **why** a topic matters before giving commands or syntax.
- Keep examples small enough to type and understand.
- Link to deeper material rather than reproducing a textbook chapter.
- Avoid assuming that a reader has studied computer science or advanced mathematics.
- Avoid Conda-based Python setup in this repository.

## Pull-request checklist

Before opening a pull request, check that internal Markdown links still work, code blocks are complete, and any new external resource is clearly labelled by level or purpose.
